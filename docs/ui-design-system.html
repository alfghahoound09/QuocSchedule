🎨 QuocSchedule — Design System & UI Improvements

v0.2.1 — Modern Deep Dark Mode with High-Contrast Information Hierarchy

Design Philosophy: "Glance & Go"

Students need to check room, time, and class in under 3 seconds. Our design prioritizes:

  • Clean & Zero Clutter: Every pixel serves a purpose
  • High Contrast: Text-background ratios meet WCAG AA+ standards
  • Information Hierarchy: Critical info (room, time) sized prominently
  • Deep Dark Mode: Eye-friendly for long study sessions

Design System Summary

🎯 Problem Solved
Students need critical info (room, time, subject) in under 3 seconds. Deep dark mode + high-contrast typography + color-coded subjects = instant recognition.
🎨 Visual Identity
Modern Material 3 deep dark (#0F172A background, #1E293B surfaces) with Emerald Green accents. 7-color subject palette ensures no two subjects share colors.
⚡ Performance
All colors pre-computed via getSubjectColor(). No runtime palette generation. Current time line updates at 1Hz. No jank.
♿ Accessibility
WCAG AA+ contrast ratios on all text. Room numbers in bold + distinct color (Yellow). Subject emojis + text for recognition. No pure-color-only information.
