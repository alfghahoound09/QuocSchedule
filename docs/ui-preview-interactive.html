Color Usage Guidelines

🟢 Accent Green (#34D399)

Today column highlight, active navigation, live session indicator

🟡 Warning Yellow (#F59E0B)

Room number badge — most important info for navigation

🔴 Error Red (#EF4444)

Current time line, urgent status, errors

💙 Primary Blue (#60A5FA)

CTA buttons, primary actions, FAB

🩷 Exam Pink (#EC4899)

Exam cards, SBD badges, special events

🌈 Subject Palette (7 colors)

Left accent borders, card backgrounds — instant visual recognition
